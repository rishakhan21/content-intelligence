# content-intelligence
Unstructured data project analyzing social media captions.

## Assignment Overview
 analyzes unstructured social media caption text and changes it into structured data. The goal was to clean raw caption text, extract hashtags, etc.

## Data Description
The dataset consists of short form social media in captions with text, emojis, punctuation, and hashtags. The captions were stored in a raw text file and required preprocessing.

## Objectives
- Transform unstructured caption text into structured data
- Extract hashtags 
- Clean text 
- Identify common word patterns and themes
- Visualize hashtag frequency

## Tools & Technologies
- Python
- Regular Expressions
- Pandas
- Matplotlib
- Collections

## Workflow
1. Load raw caption text from a `.txt` file
2. Extract hashtags
3. Remove punctuation and normalize text 
4. Perform word frequency 
5. Visualize top hashtags


## Key Insights
- Academic hashtags appeared most 
- Even readable text requires normalization 
- Small inconsistencies (capitalization, punctuation, symbols) can impact results.
- Transforming text into structured format makes it clearer
